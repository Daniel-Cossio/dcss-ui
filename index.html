⚡ Componentes Interactivos (Vanilla JS)

Notificaciones flotantes Toast, Modales accesibles, Dropdowns, Pestañas fluidas y Barra Lateral Drawer.

1. Notificaciones Toast Flotantes

Dispara notificaciones auto-descartables con iconos semánticos en cualquiera de las 4 esquinas de la pantalla.

JavaScript — API Toast 
// Notificación toast básica
DCSS.toast({
  message: 'Operación realizada con éxito',
  type: 'success', // 'success' | 'danger' | 'warning' | 'info'
  duration: 4000,
  position: 'top-right' // 'top-right' | 'top-left' | 'bottom-right' | 'bottom-left'
});

// Atajos de conveniencia
DCSS.toast.success('¡Guardado!');
DCSS.toast.danger('Error al conectar');

2. Diálogos Modales Accesibles

Modales accesibles con soporte de tecla ESC, cierre al hacer clic en el backdrop y bloqueo de scroll corporal.

Modal Estilo Raycast

Este diálogo combina la estética de superficies obsidiana de Raycast con desenfoque de fondo profundo (backdrop-filter: blur(24px) saturate(190%)) y la barra inferior de acciones rápidas contextuales.

Puedes interactuar con los atajos rápidos de la barra inferior o cerrarlo pulsando la tecla Esc o haciendo clic en el backdrop oscuro exterior.

↵ Confirmar Esc Cancelar
Atajos activos
HTML & JS — Modales 
<!-- Trigger declarativo -->
<button class="dcss-btn dcss-btn-primary" data-dcss-modal-target="#mi-modal">Abrir</button>

<!-- Creación programática vía JS -->
DCSS.modal.create({
  title: 'Confirmar eliminación',
  content: '¿Está seguro de eliminar este elemento? Esta acción no se puede deshacer.',
  confirmText: 'Eliminar',
  cancelText: 'Cancelar',
  onConfirm: () => DCSS.toast.danger('Elemento eliminado')
});

4. Pestañas Fluidas (Tabs)

Sistema de pestañas accesible con animaciones sutiles y navegación entre paneles.

Panel 1: Bienvenido a dcss-ui. Diseñado para integrarse en microservicios, dashboards FastAPI y aplicaciones web modernas sin sobrecarga de dependencias.

Panel 2: Ajustes del sistema. Puedes configurar tus tokens mediante variables CSS y sincronizar el tema oscuro/claro automáticamente.

Panel 3: Rendimiento óptimo con < 40KB CSS minificado y < 21KB JS standalone. Cero dependencias npm en producción.
